Some items we can buy to add to our collection. Other items we can borrow for you from other libraries through Interlibrary Loan.

Please note: You are able to request up to 20 items each month. You can always check the status of your request by clicking 'Check My Requests.' If you need any help completing the form below, please contact Ask KCLS or visit your local library.
